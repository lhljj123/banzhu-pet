# 伴桌小花猫

一只常驻 Windows 桌面的 3D 久坐监督猫猫。它不是网页，而是透明、无边框、可拖动的真正桌宠。

## 工作方式

- 登录 Windows 后自动启动，并从亮屏开始累计时间。
- 屏幕亮起时后台自动开始或继续计时，不需要人为点击开始。
- 每次亮屏时，3D 猫猫在桌面右下角出现 2 分钟，然后自动隐藏，后台继续计时。
- 连续使用到 55 分钟时，猫猫再次自动出现并提醒保存工作。
- 猫猫出现时可以按住身体拖动，右键查看本轮与今日数据。
- 猫猫拥有实时光影，会跟随鼠标转头，并能眨眼、摆尾、招手、伸懒腰和睡觉。
- 久坐过程中猫猫的臀部会逐渐横向坐扁，两只后爪也会向外滑。
- 连续使用 55 分钟时，猫猫自动重新出现并提醒保存工作。
- 连续使用 60 分钟后，猫猫会放大并接管全部显示器，不再显示传统提示页面。
- 十分钟休息期间，猫猫会活动并从坐扁状态逐渐恢复。
- 休息 10 分钟后才能继续使用。
- 锁屏、息屏或休眠不足 8 分钟，仍计入这一轮连续使用时间。
- 锁屏、息屏或休眠达到 8 分钟，本轮计时归零。

> Windows 安全界面、任务管理器及系统快捷键不受应用拦截。这是操作系统的安全边界。

## 本地运行

需要 Node.js 20 或更高版本。

```powershell
npm install
npm start
```

## 打包 Windows 安装程序

```powershell
npm run dist
```

安装程序会生成到 `release/` 目录。
