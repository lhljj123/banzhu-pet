# 伴桌小花猫

一只常驻 Windows 桌面的久坐监督小花猫。它不是网页，而是透明、无边框、可拖动的真正桌宠。

## 工作方式

- 登录 Windows 后自动启动，并从亮屏开始累计时间。
- 小花猫默认待在桌面右下角，可以拖动位置，双击查看今日数据。
- 关闭桌宠只会隐藏，后台计时与系统托盘仍继续运行。
- 花猫会随久坐逐渐疲惫，并在连续使用 55 分钟时主动提醒。
- 连续使用 60 分钟后，在全部显示器上打开置顶全屏休息页。
- 休息 10 分钟后才能继续使用。
- 锁屏、息屏或休眠不足 8 分钟，仍计入这一轮连续使用时间。
- 锁屏、息屏或休眠达到 8 分钟，本轮计时归零。

> Windows 安全界面、任务管理器及系统快捷键不受应用拦截。这是操作系统的安全边界。

## 本地运行

需要 Node.js 20 或更高版本。

```powershell
npm install
npm start
```

## 打包 Windows 安装程序

```powershell
npm run dist
```

安装程序会生成到 `release/` 目录。
